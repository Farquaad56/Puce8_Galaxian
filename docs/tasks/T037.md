# T037 : Golden : valider la trace CPU MAME contre l'émulateur sur 3 images

> Avant de commencer : lis `docs/tasks/_REGLES.md`. Dossier de travail : `H:\__Emulator__\Puce8_Galaxian`.
> Tu n'as AUCUNE décision à prendre. Exécute les étapes dans l'ordre. Si une sortie diffère de la sortie attendue : STOP, bloque la tâche (voir _REGLES.md §4).

1. Ouvre PowerShell et place-toi dans le dépôt :

````powershell
cd H:\__Emulator__\Puce8_Galaxian
````
2. Lance 1 image côté MAME (trace CPU+bus) et côté émulateur, puis compare le début :

````powershell
& .\tools\golden\run-golden.ps1 -Frames 3 -Mode cpu
Get-Content golden\mame_cpu.log -TotalCount 5
Get-Content golden\emu_cpu.log -TotalCount 5
````

   Sortie attendue :

````text
(5 lignes C de MAME) puis (5 lignes C de l'émulateur)
Les colonnes pc..sp des 5 lignes doivent être identiques.
````

3. Si `golden\mame_cpu.log` est vide ou ne contient pas de lignes commençant par `C ` : bloque la tâche (copie les 20 premières lignes de `golden\mame_raw.log`).
4. Si les lignes existent mais que les registres diffèrent dès la première ligne, bloque la tâche en copiant les 5 lignes MAME et les 5 lignes émulateur.
5. Si les 5 premières lignes concordent (colonnes pc..sp), la tâche est terminée. Les colonnes `frame vpos hpos tstate` peuvent différer : c'est attendu et traité en T040.

## Terminé quand

Toutes les étapes ci-dessus sont faites ET chaque « Sortie attendue » est obtenue. Marque alors la tâche terminée avec un résumé d'UNE ligne (ce qui a été créé + résultat des tests).
