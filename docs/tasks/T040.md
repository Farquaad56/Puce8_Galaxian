# T040 : Campagne 1 : trace CPU 700 images, MAME contre émulateur (registres puis tstate)

> Avant de commencer : lis `docs/tasks/_REGLES.md`. Dossier de travail : `H:\__Emulator__\Puce8_Galaxian`.
> Tu n'as AUCUNE décision à prendre. Exécute les étapes dans l'ordre. Si une sortie diffère de la sortie attendue : STOP, bloque la tâche (voir _REGLES.md §4).

1. Ouvre PowerShell et place-toi dans le dépôt :

````powershell
cd H:\__Emulator__\Puce8_Galaxian
````
2. Lance la campagne CPU sur 700 images (≈ 4,6 millions de lignes, plusieurs minutes) :

````powershell
& .\tools\golden\run-golden.ps1 -Frames 700 -Mode cpu
````
3. Tronque les deux fichiers au même nombre de lignes puis compare les registres seuls (aucune tolérance de temps) :

````powershell
$n = [Math]::Min((Get-Content golden\mame_cpu.log | Measure-Object -Line).Lines, (Get-Content golden\emu_cpu.log | Measure-Object -Line).Lines)
Get-Content golden\mame_cpu.log -TotalCount $n | Set-Content golden\mame_cpu.cut -Encoding ascii
Get-Content golden\emu_cpu.log -TotalCount $n | Set-Content golden\emu_cpu.cut -Encoding ascii
.\target\release\puce8-galaxian.exe diff golden\mame_cpu.cut golden\emu_cpu.cut
````

   Sortie attendue :

````text
IDENTIQUE : <n> lignes comparées
````

4. Si `IDENTIQUE` : étape suivante. Sinon : bloque la tâche en copiant le rapport complet. Un écart de registres signifierait que le CPU ou l'IRQ/NMI diffère (analyse = tâche d'architecte, pas la tienne).
5. Avec tolérance sur le temps (résultat informatif à recopier dans le résumé) :

````powershell
.\target\release\puce8-galaxian.exe diff golden\mame_cpu.cut golden\emu_cpu.cut --tol-tstate 0
````

   Sortie attendue :

````text
IDENTIQUE : ... (ou ÉCART : copie la ligne « tstate X vs Y »)
````

## Terminé quand

Toutes les étapes ci-dessus sont faites ET chaque « Sortie attendue » est obtenue. Marque alors la tâche terminée avec un résumé d'UNE ligne (ce qui a été créé + résultat des tests).
