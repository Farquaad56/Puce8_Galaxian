# T039 : Golden : premier WAV MAME et comparaison de format avec l'émulateur

> Avant de commencer : lis `docs/tasks/_REGLES.md`. Dossier de travail : `H:\__Emulator__\Puce8_Galaxian`.
> Tu n'as AUCUNE décision à prendre. Exécute les étapes dans l'ordre. Si une sortie diffère de la sortie attendue : STOP, bloque la tâche (voir _REGLES.md §4).

1. Ouvre PowerShell et place-toi dans le dépôt :

````powershell
cd H:\__Emulator__\Puce8_Galaxian
````
2. Son : 10 secondes de MAME en WAV 48 kHz :

````powershell
& 'X:\Mame_0287\mame.exe' galaxian -rompath 'X:\Mame_0287\roms' -wavwrite golden\mame_audio.wav -samplerate 48000 -video none -nothrottle -seconds_to_run 10 -skip_gameinfo
Test-Path golden\mame_audio.wav
````

   Sortie attendue :

````text
True
````
3. Même durée côté émulateur (600 images = 9,9 s) :

````powershell
.\target\release\puce8-galaxian.exe run 'X:\Mame_0287\roms\galaxian.zip' --frames 600 --wav golden\emu_audio.wav
.\target\release\puce8-galaxian.exe wav-compare golden\mame_audio.wav golden\emu_audio.wav
````

   Sortie attendue :

````text
rate 48000/48000 n ... rms_a ... rms_b ... rms_diff ... corr ...
````

4. Recopie la ligne `rate ...` dans le résumé de la tâche. Pendant l'attract sans entrée le son est quasi silencieux : une corrélation basse est NORMALE ici. Cette tâche ne sert qu'à vérifier que les deux WAV se lisent et ont le même taux (48000).

## Terminé quand

Toutes les étapes ci-dessus sont faites ET chaque « Sortie attendue » est obtenue. Marque alors la tâche terminée avec un résumé d'UNE ligne (ce qui a été créé + résultat des tests).
