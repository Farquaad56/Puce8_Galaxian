# T050 : Mesure : date exacte des écritures 7004 (étoiles) vue par MAME et par l'émulateur

> Avant de commencer : lis `docs/tasks/_REGLES.md`. Dossier de travail : `H:\__Emulator__\Puce8_Galaxian`.
> Tu n'as AUCUNE décision à prendre. Exécute les étapes dans l'ordre. Si une sortie diffère de la sortie attendue : STOP, bloque la tâche (voir _REGLES.md §4).

1. Ouvre PowerShell et place-toi dans le dépôt :

````powershell
cd H:\__Emulator__\Puce8_Galaxian
````
Le document `docs/spec/CALIBRATION.md` (arbre de décision) est déjà dans le dépôt.

2. Lis `golden\mame_bus.f` et `golden\emu_bus.f` (créés en T041) : repère la première écriture `W 7004` (stars on) dans chaque fichier.

````powershell
Select-String -Path golden\mame_bus.f,golden\emu_bus.f -Pattern ' W 7004 ' -List | ForEach-Object { $_.Path + ': ' + $_.Line }
````

Sortie attendue : une ligne par fichier, de la forme `B <frame> <vpos> <hpos> W 7004 00 <pc>` (la première, à data=00, est l'extinction initiale).
3. Cherche la première écriture `W 7004 01` dans les deux fichiers :

````powershell
Select-String -Path golden\mame_bus.f,golden\emu_bus.f -Pattern ' W 7004 01 ' -List | ForEach-Object { $_.Path + ': ' + $_.Line }
````

4. Recopie les deux lignes dans le résumé de la tâche, avec la différence `vpos` et `hpos` entre MAME et l'émulateur. Ne modifie aucun code. L'architecte utilisera cette mesure pour décider du décalage d'écriture à appliquer (nombre de T-states) : voir `docs/spec/CALIBRATION.md`.

## Terminé quand

Toutes les étapes ci-dessus sont faites ET chaque « Sortie attendue » est obtenue. Marque alors la tâche terminée avec un résumé d'UNE ligne (ce qui a été créé + résultat des tests).
