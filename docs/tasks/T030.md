# T030 : Ancre 1 : 3 images de la ROM réelle (CRC vidéo et watchdog)

> Avant de commencer : lis `docs/tasks/_REGLES.md`. Dossier de travail : `H:\__Emulator__\Puce8_Galaxian`.
> Tu n'as AUCUNE décision à prendre. Exécute les étapes dans l'ordre. Si une sortie diffère de la sortie attendue : STOP, bloque la tâche (voir _REGLES.md §4).

1. Ouvre PowerShell et place-toi dans le dépôt :

````powershell
cd H:\__Emulator__\Puce8_Galaxian
````
2. Lance 3 images de la vraie ROM :

````powershell
$zip = 'X:\Mame_0287\roms\galaxian.zip'
.\target\release\puce8-galaxian.exe run $zip --frames 3
````

   Sortie attendue :

````text
V 0 37EB91A9
V 1 37EB91A9
V 2 37EB91A9
watchdog_fired=false pc=1AB1
````

3. La sortie doit être IDENTIQUE, mot pour mot (les 3 CRC vidéo sont égaux car l'écran est noir pendant le boot ; `pc=1AB1` est l'adresse de la boucle d'attente du jeu).
4. Génère une image PPM pour contrôle visuel (facultatif, n'échoue jamais) :

````powershell
.\target\release\puce8-galaxian.exe run $zip --frames 400 --dump-ppm golden\boot400.ppm
````

## Terminé quand

Toutes les étapes ci-dessus sont faites ET chaque « Sortie attendue » est obtenue. Marque alors la tâche terminée avec un résumé d'UNE ligne (ce qui a été créé + résultat des tests).
