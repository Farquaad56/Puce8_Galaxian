# T001 : Dépôt : Cargo.toml racine, .gitignore, premier commit

> Avant de commencer : lis `docs/tasks/_REGLES.md`. Dossier de travail : `H:\__Emulator__\Puce8_Galaxian`.
> Tu n'as AUCUNE décision à prendre. Exécute les étapes dans l'ordre. Si une sortie diffère de la sortie attendue : STOP, bloque la tâche (voir _REGLES.md §4).

1. Ouvre PowerShell et place-toi dans le dépôt :

````powershell
cd H:\__Emulator__\Puce8_Galaxian
````
2. Vérifie l'outillage :

````powershell
git --version
cargo --version
rustc --version
git status -sb
````

   Sortie attendue :

````text
git version 2.x ...
cargo 1.8x ou plus
rustc 1.8x ou plus
## main...origin/main   (des fichiers non suivis docs/ tasks/ tools/ sont normaux)
````
3. Si la branche s'appelle `master`, renomme-la :

````powershell
git branch -M main
````

4. Crée (ou remplace ENTIÈREMENT) le fichier `Cargo.toml` avec EXACTEMENT ce contenu (copie caractère par caractère, ne change rien, pas même les commentaires) :

````toml
[workspace]
resolver = "2"
members = ["crates/galaxian-core", "crates/galaxian-cli"]

[workspace.package]
version = "0.1.0"
edition = "2021"
license = "MIT OR Apache-2.0"
authors = ["Farquaad56"]

[profile.release]
opt-level = 3
lto = "thin"
codegen-units = 1

[profile.test]
opt-level = 2
````

5. Crée (ou remplace ENTIÈREMENT) le fichier `.gitignore` avec EXACTEMENT ce contenu (copie caractère par caractère, ne change rien, pas même les commentaires) :

````text
/target
/roms/
/golden/*.log
/golden/*.png
/golden/*.wav
/golden/*.zst
*.zip
````
6. Crée les dossiers vides utiles (avec un fichier `.gitkeep`) :

````powershell
New-Item -ItemType Directory -Force crates, golden, roms | Out-Null
New-Item -ItemType File -Force golden\.gitkeep, roms\.gitkeep | Out-Null
````
7. Commit (uniquement ces fichiers) :

````powershell
git add "Cargo.toml" ".gitignore" "docs" "tasks" "tools" "golden/.gitkeep" "roms/.gitkeep"
git commit -m "chore: workspace racine et paquet de tâches"
````

Note : `cargo` ne peut pas encore compiler (les crates arrivent aux tâches T002 et T003). C'est normal.

## Terminé quand

Toutes les étapes ci-dessus sont faites ET chaque « Sortie attendue » est obtenue. Marque alors la tâche terminée avec un résumé d'UNE ligne (ce qui a été créé + résultat des tests).
