# T041 : Campagne 2 : accès bus 700 images (contenu puis timing)

> Avant de commencer : lis `docs/tasks/_REGLES.md`. Dossier de travail : `H:\__Emulator__\Puce8_Galaxian`.
> Tu n'as AUCUNE décision à prendre. Exécute les étapes dans l'ordre. Si une sortie diffère de la sortie attendue : STOP, bloque la tâche (voir _REGLES.md §4).

1. Ouvre PowerShell et place-toi dans le dépôt :

````powershell
cd H:\__Emulator__\Puce8_Galaxian
````
2. Trace du bus déjà générée en T040. Compare R/W, adresse, donnée (sans pc, sans temps) :

````powershell
foreach ($f in 'mame_bus','emu_bus') { Get-Content golden\$f.log | Where-Object { $_ -match '^B \d+ \d+ \d+ [RW] (5[0-7]|[67][0-9A-F])' } | Set-Content golden\$f.f -Encoding ascii }
.\target\release\puce8-galaxian.exe diff golden\mame_bus.f golden\emu_bus.f --ignore-pc --ignore-vpos
````

   Sortie attendue :

````text
IDENTIQUE : <n> lignes comparées
````
3. Puis avec vpos exigé (informatif) :

````powershell
.\target\release\puce8-galaxian.exe diff golden\mame_bus.f golden\emu_bus.f --ignore-pc
````

   Sortie attendue :

````text
IDENTIQUE ... ou ÉCART ... (copie le rapport dans le résumé)
````
4. Puis avec vpos et hpos à ±200 cycles quartz (informatif) :

````powershell
.\target\release\puce8-galaxian.exe diff golden\mame_bus.f golden\emu_bus.f --ignore-pc --tol-hpos 200
````

   Sortie attendue :

````text
IDENTIQUE ... ou ÉCART ...
````

Si l'étape 2 donne un écart, bloque la tâche. Les étapes 3 et 4 sont informatives : recopie leurs résultats, ne bloque pas.

## Terminé quand

Toutes les étapes ci-dessus sont faites ET chaque « Sortie attendue » est obtenue. Marque alors la tâche terminée avec un résumé d'UNE ligne (ce qui a été créé + résultat des tests).
