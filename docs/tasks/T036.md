# T036 : Golden : valider MAME 0.287, le romset et l'API Lua des ports

> Avant de commencer : lis `docs/tasks/_REGLES.md`. Dossier de travail : `H:\__Emulator__\Puce8_Galaxian`.
> Tu n'as AUCUNE décision à prendre. Exécute les étapes dans l'ordre. Si une sortie diffère de la sortie attendue : STOP, bloque la tâche (voir _REGLES.md §4).

1. Ouvre PowerShell et place-toi dans le dépôt :

````powershell
cd H:\__Emulator__\Puce8_Galaxian
````
2. Vérifie la version de MAME et que le jeu est reconnu :

````powershell
& 'X:\Mame_0287\mame.exe' -version
& 'X:\Mame_0287\mame.exe' -verifyroms galaxian -rompath 'X:\Mame_0287\roms'
````

   Sortie attendue :

````text
0.287 (...)
romset galaxian [galaxian] is good
````
3. Liste les noms de champs du port IN0 (diagnostic Lua, aucun fichier du dépôt modifié) :

````powershell
$lua = Join-Path $env:TEMP 'ports.lua'
@'
local p = manager.machine.ioport.ports[':IN0']
for name, f in pairs(p.fields) do print('FIELD', name, string.format('mask=%02X', f.mask)) end
emu.add_machine_frame_notifier(function() manager.machine:exit() end)
'@ | Set-Content $lua -Encoding ascii
& 'X:\Mame_0287\mame.exe' galaxian -rompath 'X:\Mame_0287\roms' -autoboot_script $lua -video none -sound none -seconds_to_run 2 -skip_gameinfo
````

   Sortie attendue :

````text
FIELD  Coin 1  mask=01
FIELD  P1 Left  mask=04
... (une ligne FIELD par champ ; les masques 01 02 04 08 10 20 40 80 doivent tous apparaître)
````

4. Si la commande Lua échoue avec « attempt to index a nil value » ou « mask » inconnu : bloque la tâche en copiant le message. (Cela signifie que l'API Lua d'accès aux ports de cette version doit être adaptée par l'architecte : n'essaie pas de la deviner.)
