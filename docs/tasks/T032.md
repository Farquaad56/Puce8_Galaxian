# T032 : Ancre 3 : trace du bus d'une image (1310 lignes, 14 premières exactes)

> Avant de commencer : lis `docs/tasks/_REGLES.md`. Dossier de travail : `H:\__Emulator__\Puce8_Galaxian`.
> Tu n'as AUCUNE décision à prendre. Exécute les étapes dans l'ordre. Si une sortie diffère de la sortie attendue : STOP, bloque la tâche (voir _REGLES.md §4).

1. Ouvre PowerShell et place-toi dans le dépôt :

````powershell
cd H:\__Emulator__\Puce8_Galaxian
````
2. Trace du bus de 1 image :

````powershell
$zip = 'X:\Mame_0287\roms\galaxian.zip'
.\target\release\puce8-galaxian.exe trace-bus $zip --frames 1 --out golden\ref_bus1.log
(Get-Content golden\ref_bus1.log | Measure-Object -Line).Lines
Get-Content golden\ref_bus1.log -TotalCount 14
````

   Sortie attendue :

````text
1310
B 0 0 96 W 7001 00 0001
B 0 0 342 W 5000 10 1A5C
B 0 0 468 W 5001 10 1A5C
B 0 0 594 W 5002 10 1A5C
B 0 0 720 W 5003 10 1A5C
B 0 0 846 W 5004 10 1A5C

B 0 1 576 W 500B 10 1A5C
B 0 1 702 W 500C 10 1A5C
````

3. Les 14 premières lignes doivent être IDENTIQUES et le total doit être `1310`.
   Format d'une ligne `B` : `B frame vpos hpos R|W addr data pc` (8 champs). Seuls les accès 5000-7FFF sont journalisés.
