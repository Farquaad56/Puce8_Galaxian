# T075 : GUI : recette manuelle (affichage, pièce, partie, clavier)

> Avant de commencer : lis `docs/tasks/_REGLES.md`. Dossier de travail : `H:\__Emulator__\Puce8_Galaxian`.
> Tu n'as AUCUNE décision à prendre. Exécute les étapes dans l'ordre. Si une sortie diffère de la sortie attendue : STOP, bloque la tâche (voir _REGLES.md §4).

1. Ouvre PowerShell et place-toi dans le dépôt :

````powershell
cd H:\__Emulator__\Puce8_Galaxian
````
2. Lance l'émulateur graphique :

````powershell
.\target\release\puce8-galaxian-gui.exe 'X:\Mame_0287\roms\galaxian.zip'
````

3. Contrôle visuel, dans l'ordre, et coche chaque point dans le résumé de la tâche :
   a. Une fenêtre « Puce8 Galaxian » s'ouvre avec une image noire puis l'écran de démonstration (texte « GALAXIAN », étoiles qui défilent).
   b. Touche `5` : insère une pièce → le texte « CREDIT 1 » apparaît en bas.
   c. Touche `1` : démarre une partie 1 joueur → le vaisseau apparaît en bas, les extraterrestres en haut.
   d. Flèches gauche/droite déplacent le vaisseau ; `Espace` tire.
   e. Touche `Échap` ferme la fenêtre.
4. Si un point échoue : bloque la tâche en indiquant la lettre du point.
